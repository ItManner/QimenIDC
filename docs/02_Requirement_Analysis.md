# 商业化 IDC 云管系统 - 02. 需求与用户研究阶段详细说明

本阶段的核心是清晰定义**三端（授权中心、Web 主控、KVM 被控）**的功能边界。绝不允许出现功能冗余或职责不清。

## 2.1 独立授权管理系统（Auth Center）需求

这是官方自己使用的命根子系统，不对外公开，专门用来赚钱和管客户。

### 2.1.1 授权生成与管理
- **生成 License**：支持批量生成或单条生成，绑定套餐类型（基础版/专业版/白标定制版）、有效期（如 30 天/1 年/永久）。
- **配额管理**：管理员可手动修改每个 License 的可用母鸡配额数。
- **绑定换绑**：记录每个 License 激活时的机器特征码（Hardware ID）。支持管理员后台一键清空绑定记录，供客户更换服务器。
- **状态冻结**：若发现盗版/破解/超限，管理员可一键拉黑 License。

### 2.1.2 心跳监控与审计
- **心跳接收**：每隔一定时间（如 1 小时），接收所有合法主控发来的状态报告（包括：当前主控 IP、管理的母鸡总数、活跃虚拟机总数）。
- **告警触发**：如果一个 License 超过 24 小时未上报心跳，或上报的母鸡数量超过已购配额，授权中心将其标记为异常，并在后台高亮显示。

## 2.2 Web 主控端（Master Panel）核心需求

这是卖给 IDC 老板的面板，分为“管理员后台”和“用户前台”。

### 2.2.1 资源接入与管理（管理员核心）
- **母鸡接入管理**：
  - 点击“添加节点”，系统生成一段唯一的 Shell 命令，如：`wget -qO- https://your-panel.com/agent/install.sh | bash -s "NODE_TOKEN_XXXX"`。
  - 管理员在物理机执行后，主控后台能看到该节点上线，并展示其实时 CPU 负载、内存余量、磁盘空间和网卡流量。
- **IP 地址池管理（IPAM）**：
  - 录入购买的公网 IP 段（如 `192.168.1.0/24`，网关，子网掩码）。
  - 支持给特定套餐或特定母鸡分配特定 IP 段。
- **镜像与模板库**：
  - 管理可用的操作系统模板（Ubuntu 22.04、Debian 12、Windows Server 等）。
  - 主控端统一下发镜像下载链接给各母鸡，由母鸡自行拉取并缓存。
- **产品套餐定义**：
  - 定义 CPU 核心数、内存大小、系统盘大小、每月可用流量上限、峰值带宽。

### 2.2.2 租户与资源分配（剥离计费）
- **账户体系**：仅提供租户的创建与管理。系统自身不包含充值、账单、支付等财务模块。
- **资源划拨**：管理员直接为特定租户分配虚拟机，或通过开放 API（供外部财务系统如 WHMCS、Hostbill、自有商城调用）来触发虚拟机的创建。
- **到期与停机（API 驱动）**：外部财务系统通过调用主控的 API，执行虚拟机的挂起（Suspend）或销毁（Destroy），本系统仅被动执行资源回收。

### 2.2.3 虚拟机控制台（用户核心体验）
- **基础操作面板**：用户登录后，看到自己购买的 VPS 列表，支持开机、关机、强制重启、重装系统。
- **Web VNC 远程桌面**：用户点击“VNC 控制台”，弹出一个网页终端，即使 SSH 连不上也能通过 VNC 进系统排查。
- **资源监控图表**：展示该 VPS 的 CPU 使用率、出入带宽图表（数据由被控端定期上报）。

## 2.3 KVM 被控端（Node Agent）核心需求

部署在物理母鸡上的“黑盒”守护进程，它是干脏活累活的执行者，没有 Web 界面。

### 2.3.1 全自动一键安装（极其关键）
- 这是客户体验的决定性环节。一键脚本必须完成：
  - 自动检测系统发行版（仅限支持的纯净版 Linux）。
  - 自动通过包管理器安装 `qemu-kvm`、`libvirt-daemon-system`、`bridge-utils`、`iptables`。
  - 自动创建并接管物理网卡，建立名为 `br0` 的网桥（难度极高，必须处理不同系统的网络配置文件差异）。
  - 下载编译好的 Go 二进制 Agent 文件，注册为 Systemd 服务并启动。

### 2.3.2 虚拟机生命周期执行（对接 libvirt）
- 接收主控下发的 gRPC/HTTP 指令。
- **秒级创建**：使用 Qcow2 镜像的 Backing File 特性，不要全盘复制，实现数秒内克隆出虚拟机磁盘。
- **Cloud-Init 注入**：将主控下发的 IP、网关、初始 Root 密码生成 Cloud-Init ISO，挂载给虚拟机，实现开机自动配置网络。
- 启、停、删、硬重启操作。

### 2.3.3 底层资源控制与隔离
- **网络限制**：根据套餐，调用 Linux 的 `tc` (Traffic Control) 命令，限制虚拟机网卡的上下行带宽速率。
- **MAC 防欺骗**：调用 `iptables` 或 `ebtables`，强制绑定虚拟机的 MAC 地址与分配的 IP，防止客户在 VPS 内私自修改 IP 导致同网段其他人断网。
- **流量统计**：通过读取网卡的 `/proc/net/dev`，每隔一定时间汇总当前虚拟机的消耗流量，上报给主控扣除套餐额度。
